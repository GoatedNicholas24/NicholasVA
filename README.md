# Watiti Nicholas | AI Automation Portfolio

A responsive, single-page portfolio built with semantic HTML, CSS, and plain JavaScript. There are no package dependencies or build step.

## Project files

- `index.html` contains the accessible page structure, social metadata, navigation, and the main content sections.
- `styles.css` contains the n8n-inspired colors, responsive layouts, light/dark themes, workflow visuals, and reduced-motion-aware transitions.
- `script.js` contains the real-estate workflow demos, six full articles, services, rendering helpers, mobile navigation, theme persistence, and contact-form behavior.
- `watiti-nicholas.jpg` is the profile portrait used in the hero workflow panel.
- `README.md` explains how to preview and personalize the site.

## Preview

Open `index.html` directly in a browser, or use the VS Code Live Server extension for local preview. The site does not require a server to function.

## Personalize before publishing

1. Update the canonical URL and Open Graph descriptions in `index.html` when you publish the site.
2. The contact form opens a pre-filled message to `nicholaswatiti23@gmail.com` in the visitor's email app. A direct-to-inbox form submission requires a server or form service.
3. Replace the suggested workflow ideas in the `projects` array in `script.js` with your actual n8n builds, screenshots, outcomes, and demo links as you prepare them.
4. The six articles are written in the `articles` array in `script.js` and expand inline from the Writing section.
